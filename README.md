# Stitch Theory

## Project Overview

Stitch Theory is a modern e-commerce fashion website developed to provide users with a seamless online shopping experience.

The project includes product browsing, cart management, discount coupon application, address management, and payment success workflow.

---

## Technologies Used

- HTML
- CSS
- JavaScript
- Bootstrap
- LocalStorage

---

## Features

### User Features

- Browse Fashion Products
- Add Products to Cart
- Increase Product Quantity
- Decrease Product Quantity
- Remove Products from Cart
- View Cart Total
- Apply Discount Coupon
- Address Form Submission
- Payment Gateway Page
- Payment Success Confirmation
- Data Persistence using LocalStorage

---

## Project Modules

### Home Page
Displays products and navigation menu.

### Product Section
Shows fashion product listings.

### Cart Management
- Add to cart
- Update quantity
- Remove products
- Auto price calculation

### Coupon System
Apply discount coupon for offers.

### Address Page
User enters delivery address details.

### Payment Page
Handles payment flow simulation.

### Success Page
Displays successful order confirmation.

---

## How to Run

1. Download project files
2. Open project in VS Code
3. Run using Live Server
4. Browse products
5. Add to cart
6. Complete checkout process
